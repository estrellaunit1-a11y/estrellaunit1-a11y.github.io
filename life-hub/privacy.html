プライバシーポリシー

life-hub（以下「本ツール」）が Google アカウントのデータをどう扱うかを説明します。

本ツールについて

本ツールは、作者本人が自分の予定とタスクを把握するために作った個人用のツールです。作者以外の利用は想定していません。

アクセスするデータ

本ツールは、利用者の許可を得たうえで、次の範囲に限って Google のデータにアクセスします。

  • Google カレンダー：予定の読み取り（変更・削除はしません）
  • Google ToDo リスト：タスクの読み取りと、利用者本人の指示によるタスクの追加（既存タスクの変更・削除はしません）
  • Gmail：利用者本人宛てのお知らせメールの送信のみ（メールを読むことはしません）

利用目的

取得したデータは、次の目的だけに使います。

  • その日の予定と期限が近いタスク、翌日の予定をまとめて、利用者本人に知らせるため
  • 利用者本人が自分の AI アシスタント（Claude Code や Codex など）から本ツールを呼び出したときに、予定とタスクを答えるため。このとき結果は、利用者が使っている AI アシスタントに渡されます

保存

  • 予定やタスクの内容は保存しません。まとめを作る処理の間だけ使います。
  • Google へのアクセスに必要な認証情報（トークン）は、作者が管理する実行環境にだけ保存します。

第三者への提供

取得したデータを第三者に提供・販売したり、広告や AI モデルの学習に使ったりすることはありません。上記の AI アシスタントへの受け渡しは、利用者本人の操作によるものに限ります。

Google API サービスのユーザーデータに関するポリシー

本ツールによる、Google API から受け取った情報の利用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（Limited Use の要件を含む）に従います。

アクセス許可の取り消し

本ツールへのアクセス許可は、Google アカウントのサードパーティ製のアプリとサービスからいつでも取り消せます。

変更

扱うデータや利用目的が変わる場合は、このページを更新します。

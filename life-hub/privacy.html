プライバシーポリシー

life-hub（以下「本ツール」）が Google アカウントのデータをどう扱うかを説明します。

本ツールについて

本ツールは、作者本人が自分の予定とタスクを把握するために作った個人用のツールです。作者以外の利用は想定していません。

アクセスするデータ

本ツールは、利用者の許可を得たうえで、次の範囲に限って Google のデータにアクセスします。

  • Google カレンダー：予定の読み取り（変更・削除はしません）
  • Google ToDo リスト：タスクの読み取りと、利用者本人の指示によるタスクの追加・完了・期限の変更（タスクの削除や、タイトル・メモの書き換えはしません）
  • Gmail：受信メールの送信者・件名などの情報の読み取り、利用者本人が決めたルールによるラベルの付与、利用者本人宛てのお知らせメールの送信。メール本文を読むのは、Amazon.co.jp から届く注文・発送・配達のお知らせ（差出人が Amazon の決まったアドレスで、送信元の認証に合格したもの）だけです。それ以外のメール本文は使いません。メールの削除・転送や、ほかの人への送信はしません

利用目的

取得したデータは、次の目的だけに使います。

  • その日の予定と期限が近いタスク、翌日の予定、次の1週間の予定と残っているタスク、対応が必要そうなメールをまとめて、利用者本人に知らせるため
  • 利用者本人が決めたルールで受信メールにラベルを付け、対応が必要そうなメールを本人の ToDo リストに追加するため（メールの分類に AI は使いません）
  • 利用者本人の買い物を記録し、何をいつ買ったかを探せるようにするため。あわせて、何度か買っている物の次に買う目安と、その日に届く荷物を本人に知らせるため。Amazon のお知らせメールから取り出すのは、注文番号・注文日・商品名・数量・価格・お届け予定日・配送の状況だけです。宛名・住所・支払い方法は取り出しません
  • 利用者本人が自分の AI アシスタント（Claude Code や Codex、スマートフォンの Claude アプリなど）から本ツールを呼び出したときに、予定とタスクを答え、指示されたタスクの操作を行うため。このとき結果は、利用者が使っている AI アシスタントに渡されます。メールの内容は AI アシスタントに渡しません。ただし、利用者本人が作者の PC で購入履歴を調べたときは、その結果（商品名・日付・価格など）が AI アシスタントに渡ることがあります

保存

  • 予定・タスク・メールの内容は保存しません。処理の間だけ使います。ただし、対応が必要そうなメールの件名と送信者は、利用者本人の ToDo リストにタスクとして追加されます。
  • 購入履歴（Amazon のお知らせメールから取り出した上記の項目と、利用者本人が Amazon から取り寄せた注文履歴のファイルの同じ項目）は、作者の PC の中の、本人だけが読めるファイルにだけ保存します。朝のまとめのために今日届く荷物を調べるとき（GitHub Actions）は保存しません。
  • Google へのアクセスに必要な認証情報（トークン）は、作者が管理する実行環境（作者の PC、GitHub Actions のシークレット、Google Cloud の Secret Manager（東京リージョン））にだけ保存します。
  • スマートフォンから使うために、本ツールを Google Cloud Run（東京リージョン）でも動かします。ここでも予定・タスクの内容は保存せず、呼び出しの間だけ使います。呼び出せるのは、合言葉による本人確認を通った利用者本人だけです。

Google マップの利用

予定の場所までの行き方を示すため、予定の「場所」の欄の文字列と、作者が設定した自宅の位置を Google Maps Platform（Places API・Routes API）に送り、自宅からの移動時間の目安を調べます。送るのは場所の欄だけで、予定のタイトル・説明・参加者は送りません。調べた結果は保存しません。

第三者への提供

取得したデータを第三者に提供・販売したり、広告や AI モデルの学習に使ったりすることはありません。上記の AI アシスタントへの受け渡しは、利用者本人の操作によるものに限ります。

Google API サービスのユーザーデータに関するポリシー

本ツールによる、Google API から受け取った情報の利用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（Limited Use の要件を含む）に従います。

アクセス許可の取り消し

本ツールへのアクセス許可は、Google アカウントのサードパーティ製のアプリとサービスからいつでも取り消せます。

変更

扱うデータや利用目的が変わる場合は、このページを更新します。
